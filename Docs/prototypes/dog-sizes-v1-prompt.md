Use case: stylized-concept.
Asset type: ONE visual comparison concept board for the existing Mitzi side-scrolling mobile game, preview only, no gameplay redesign.
Reference image 1 (dog_idle.png): match its realistic cutout animal texture, soft lighting, detailed fur, friendly natural anatomy. It is the current golden dog style reference, not an edit target.
Reference image 2 (forest-go-under.png): game art/style and the silver grey tabby cat identity reference only. Ignore its HUD, giant obstacle tree, and text.
Create a polished wide landscape board with THREE equal columns and one common horizontal ground baseline across all three. Within EACH column show the SAME adult silver grey tabby cat at EXACTLY THE SAME SCALE, head/body/pose/markings, standing in true right-facing side profile at left, plus a different dog standing in true right-facing side profile beside it at right. Separate the animals with breathing room, all paws on the same baseline, full tails and ears visible, no occlusion. This is a coherent game concept sheet, realistic animal sprites over a very subtle pale warm forest/street-inspired backdrop, clean and easy to compare.
LEFT: small Yorkshire terrier with black/tan silky fur, withers about 0.8 times the cat's withers height.
MIDDLE: medium tricolor beagle, withers about 1.3 times the same cat's withers height.
RIGHT: larger golden retriever in the reference art style, withers about 1.8 times the same cat's withers height.
The dogs must be visibly different breeds, silhouettes and sizes, not the same dog simply resized. The CAT MUST REMAIN IDENTICAL IN SIZE across all columns. Actual dog anatomy, no clothes, accessories or aggressive expression. Subtle ground shadows. Equal camera/zoom and baseline; do not normalize all dogs to equal heights. The board is a visual prototype, not final game assets.
Typography exact Turkish text only, understated and readable, with a short header and captions:
